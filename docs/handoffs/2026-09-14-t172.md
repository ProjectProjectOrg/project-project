## Approved contracts and scope

- Jira connections persist until explicit local disconnect. Token refresh is serialized and rotated tokens are persisted atomically. There is no application-callable Atlassian revoke operation.
- Jobs are durable, revisioned, leased, and resumable. Staged manifests use `migrations/jira/<migration-id>/`; successful archives use `imports/jira/<migration-id>/`. Failed/cancelled staging is retained for 30 days.
- Mapping requires explicit decisions for identities, destination statuses, issue types, priorities, tag collisions, restricted content, attachment skips, and competing active/future sprint memberships. Status decisions may reuse an existing option or select the exact server-derived custom-status candidate. Completed sprint memberships are preserved automatically.
- Publication builds an unreachable destination first, then exposes the project/index state and marks success in one PostgreSQL transaction. Recovery must never expose a partial project.
- Jira epics, versions, and sprints import into the existing Group domain and are reported by the wizard. New epic/milestone tabs, routes, chips, or management UI are deferred to separate tickets and are not a T-172 release gate.

## Fresh-machine setup

Use the repository's normal install and database migration flow. Configure a local `.env` without committing it. Required variable names for this path are `DATABASE_URL`, `BETTER_AUTH_SECRET`, `BETTER_AUTH_URL`, `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET`, `USER_SECRET_ENCRYPTION_KEY`, `JIRA_CLIENT_ID`, `JIRA_CLIENT_SECRET`, and `PROJECTS_DIR`. Jira's OAuth callback must be exactly:

```text
<BETTER_AUTH_URL>/api/integrations/jira/oauth/callback
```

Organization storage is configured in the application, not through S3 environment variables. For local MinIO use its reachable endpoint, region, pre-created bucket, access-key id, secret access key, optional key prefix, and `forcePathStyle: true`. The standard local endpoint is `http://localhost:9000`; use the machine-appropriate reachable host when the app runs in a container.

The prior preview PostgreSQL dump, `.env`, OAuth/session state, and MinIO objects are intentionally not in Git. To preserve the exact same job across machines, transfer the private database dump and any required MinIO volume/object backup through a secure channel, keep file permissions private, use the identical `USER_SECRET_ENCRYPTION_KEY`, and restore only into an empty database. Never send secrets or the dump through Git. Without that secure state transfer, use a clean database and reconnect/rescan.
