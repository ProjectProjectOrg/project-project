# MCP Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land a working but minimal MCP server: OAuth 2.1 + PKCE + DCR via the Better Auth MCP plugin, Streamable HTTP listener at `/mcp`, a generic schema-first dispatcher, exactly one tool (`me`) reachable end-to-end, and a settings page that lists and revokes connected agents.

**Architecture:** Single Bun process. Better Auth's MCP plugin owns identity, discovery, DCR, authorize, token, consent screen, and bearer verification. `/mcp` is one new HTTP route on the existing backend that wraps `withMcpAuth` and dispatches to a generic Effect-backed catalog walker. The tool catalog lives in `packages/shared/src/mcp.ts`; handlers and the dispatcher live in `packages/backend/src/mcp/*`. No business logic duplication — handlers call existing services.

**Tech Stack:** Effect v3, `@effect/platform` HttpApi, Better Auth (with the `mcp` plugin), Drizzle, Postgres, `@modelcontextprotocol/sdk`, TanStack Start.

**Spec:** `docs/superpowers/specs/2026-05-11-mcp-server-design.md`

**Prerequisites:**

- Branches `chore/improve-atom-handling` and `chore/better-lsp-settings` are merged into the working branch (or rebased onto). The plan assumes the post-merge shape: backend services live under `packages/backend/src/Services/*`, Layers under `packages/backend/src/Layers/*`, normalized Effect imports, the `Groups` / `CurrentOrg` services exist, etc. If the merge hasn't happened, Task 0 covers it.

```ts
// packages/shared/src/mcp/Pagination.ts
import * as Schema from "effect/Schema"

export const Pagination = Schema.Struct({
  cursor: Schema.optional(Schema.String),
  limit: Schema.optional(Schema.Int.pipe(Schema.between(1, 200))),
})
export type Pagination = typeof Pagination.Type

export const Page = <A, I>(item: Schema.Schema<A, I>) =>
  Schema.Struct({
    items: Schema.Array(item),
    nextCursor: Schema.NullOr(Schema.String),
  })

export interface CursorPayload {
  readonly id: string
  readonly sort: string
}

export const encodeCursor = (p: CursorPayload): string =>
  Buffer.from(JSON.stringify(p), "utf8").toString("base64url")

export const decodeCursor = (s: string): CursorPayload =>
  JSON.parse(Buffer.from(s, "base64url").toString("utf8"))
```

```ts
// packages/backend/src/mcp/errorMap.ts
export interface McpToolErrorResult {
  readonly content: ReadonlyArray<{ readonly type: "text"; readonly text: string }>
  readonly isError: true
}

const text = (s: string): McpToolErrorResult => ({
  content: [{ type: "text", text: s }],
  isError: true,
})

export const mapToolError = (e: unknown): McpToolErrorResult => {
  if (typeof e === "object" && e !== null && "_tag" in e) {
    const tag = String((e as { _tag: unknown })._tag)
    switch (tag) {
      case "Unauthorized": return text("Unauthorized.")
      case "Forbidden":    return text("Forbidden.")
      case "NotFound":     return text("Not found.")
      case "ParseError":   return text(`Validation error: ${JSON.stringify(e)}`)
      default:             return text(`Error (${tag}).`)
    }
  }
  return text("Internal error.")
}
```

## Task 8: Backend dispatcher (generic `McpTools` walker)

**Files:**
- Create: `packages/backend/src/mcp/dispatch.ts`

This file is *not* a Layer yet — it's a pure helper that, given an `McpServer` SDK instance, a runtime, a handler map, and the catalog, registers every tool. Splitting this out from the Layer keeps the Layer thin and the registration logic unit-testable.

- [ ] **Step 1: Implement.**

```ts
// packages/backend/src/mcp/dispatch.ts
import type { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js"
import * as Schema from "effect/Schema"
import { Effect, type ManagedRuntime } from "effect"
import { McpTools, type McpToolName } from "@projectproject/shared"
import { mapToolError } from "./errorMap"

type AnyHandler = (input: any) => Effect.Effect<any, any, any>
export type HandlersMap = { readonly [K in McpToolName]: AnyHandler }

const asJsonContent = (value: unknown) => ({
  content: [
    { type: "text" as const, text: JSON.stringify(value, null, 2) },
  ],
})

export function registerAllTools<R>(
  server: McpServer,
  runtime: ManagedRuntime.ManagedRuntime<R, never>,
  handlers: HandlersMap,
): void {
  for (const name of Object.keys(McpTools) as Array<McpToolName>) {
    const spec = McpTools[name]
    const handler = handlers[name]

    server.registerTool(
      name,
      {
        description: spec.description,
        // Effect Schema implements Standard Schema v1, which the SDK accepts.
        inputSchema: Schema.standardSchemaV1(spec.input) as any,
        outputSchema: Schema.standardSchemaV1(spec.output) as any,
      },
      async (input: unknown) => {
        const program = Schema.decodeUnknown(spec.input)(input).pipe(
          Effect.flatMap((parsed) => handler(parsed)),
          Effect.flatMap((out) => Schema.encode(spec.output)(out)),
          Effect.map(asJsonContent),
        )
        try {
          return await runtime.runPromise(program as Effect.Effect<any, any, R>)
        } catch (e) {
          return mapToolError(e)
        }
      },
    )
  }
}
```

```ts
import { ServicesLayer } from "../runtime"        // post-merge: the shared services Layer

      (rt) => Effect.promise(() => rt.dispose()),
```

```ts
// packages/backend/src/mcp/route.ts
import { StreamableHTTPServerTransport } from "@modelcontextprotocol/sdk/server/streamableHttp.js"
import { withMcpAuth } from "better-auth/plugins"
import { auth } from "../auth"
import type { McpServer as SdkMcpServer } from "@modelcontextprotocol/sdk/server/mcp.js"

// Single transport instance reused across requests. The SDK is built so the
// transport multiplexes connections internally; one server + one transport per
// process is correct.
export function makeMcpRequestHandler(server: SdkMcpServer): (req: Request) => Promise<Response> {
  const transport = new StreamableHTTPServerTransport({ sessionIdGenerator: undefined })
  server.connect(transport)

  return withMcpAuth(auth, async (req, session) => {
    // session.userId is what the dispatcher's CurrentUser layer pulls. We
    // attach it via a request-scoped header the dispatcher knows to read,
    // or — preferred — by passing it through into a context the route
    // wires into the runtime per-request.
    //
    // For Foundation, the simplest correct shape: stash session.userId on
    // a per-request AsyncLocalStorage that the CurrentUser layer reads.
    // See Task 12 for that wiring.
    return await transport.handleRequest(req)
  })
}
```
