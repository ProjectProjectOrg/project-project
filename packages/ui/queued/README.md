# Queued components

Gallery pages for components that have not had their polish pass yet. They live
outside `docs/`, so the gallery doesn't list them. To start a component's pass,
move its folder back to `docs/components/<name>/` and follow the polish loop in
the `ui-components` skill.

`prototypes/` holds the first-round HTML prototypes (open one in T3 to show it).

Queue, in order: dialog, confirm-button, command-menu.
