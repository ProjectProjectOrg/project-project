The popover open on its surface, with a title, a close button, body text and actions. Click the trigger to close and reopen it.

## Usage

```tsx
import { Popover, PopoverContent, PopoverTrigger } from "@pp/ui/popover"

;<Popover>
  <PopoverTrigger
    render={
      <ToolbarButton aria-label={m.tickets_view_options_label()}>
        <SlidersHorizontal className="size-4" strokeWidth={1.75} />
        {m.tickets_view_options_label()}
      </ToolbarButton>
    }
  />
  <PopoverContent
    aria-label={m.tickets_view_options_label()}
    align="end"
    side="bottom"
    className="w-80 p-0"
  >
    <div className="space-y-2 p-3">
      <Ordering />
      <DisplayProperties />
    </div>
  </PopoverContent>
</Popover>
```

`PopoverContent` wraps Base UI's portal, positioner and popup, so placement props go straight on it. `PopoverTitle` and `PopoverClose` pass through to Base UI.

| Prop                 | Type                                     | Default    |
| -------------------- | ---------------------------------------- | ---------- |
| `side`               | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"` |
| `align`              | `"start" \| "center" \| "end"`           | `"end"`    |
| `sideOffset`         | `number`                                 | `4`        |
| `alignOffset`        | `number`                                 |            |
| `anchor`             | element, ref or virtual element          | trigger    |
| `collisionAvoidance` | Base UI collision settings               |            |
| `collisionBoundary`  | `Element \| "clipping-ancestors"`        |            |
| `collisionPadding`   | `number`                                 |            |
| `keepMounted`        | `boolean` (keep the popup in the DOM)    | `false`    |
