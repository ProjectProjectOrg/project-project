## Overview

Hover a row to show its menu.

<Demo name="overview" title="Rows" />

## Usage

```tsx
import { Reveal } from "@pp/ui/reveal"

<li className="group/reveal">
  …
  <Reveal>
    <Button variant="ghost" size="icon-xs" aria-label="Delete" />
  </Reveal>
</li>
```

| Prop        | Type        | Default |
| ----------- | ----------- | ------- |
| `className` | `string`    |         |
| `children`  | `ReactNode` |         |

## Rules

### The row is the nearest `group/reveal`

List rows, board cards, comment rows and settings rows all mark themselves `group/reveal`. Reveal never takes an option for which parent it follows.

### Visible whenever the row is in play

Hover (or the list's hover highlight), keyboard focus anywhere in the row, an open popup in the row, a selected row, and a checked or just-copied child all show it. Touch screens have no hover, so there it always shows.

### Lands with the highlight, leaves at once

In a list with the gliding highlight it shows as the highlight lands on the row, easing in over 100ms, so it never runs ahead of it; elsewhere it shows at once. Leaving hides it at once: a fade-out would keep the rows the pointer just crossed lit, a trail of them on a quick sweep. While the list is driven from the keyboard, the pointer's hover is ignored.

### Hide the wrapper, not the control

The opacity sits on Reveal's own span, so the control inside keeps its variant untouched. Position the wrapper (`className="absolute right-1"`) when the control was positioned.
