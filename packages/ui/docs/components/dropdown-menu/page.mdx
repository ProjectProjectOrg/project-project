## Overview

Every kind of row and state in one menu: the highlight resting on the first item, plain items with icons and shortcuts, a disabled item, checkbox and radio choices, a submenu and a destructive action. Hover or use the arrow keys to move the highlight.

## Usage

```tsx
import {
  DropdownMenu,
  DropdownMenuCheckboxItem,
  DropdownMenuContent,
  DropdownMenuTrigger
} from "@pp/ui/dropdown-menu"

<DropdownMenu>
  <DropdownMenuTrigger render={<Button variant="secondary" />}>
    {m.tickets_filters_tags()}
  </DropdownMenuTrigger>
  <DropdownMenuContent className="w-56">
    {tags.map((tag) => (
      <DropdownMenuCheckboxItem
        key={tag.name}
        label={tag.name}
        checked={selected.has(tag.name)}
        closeOnClick={false}
        onCheckedChange={() => toggle(tag.name)}
      >
        <TagDot color={tag.color} />
        {tag.name}
      </DropdownMenuCheckboxItem>
    ))}
  </DropdownMenuContent>
</DropdownMenu>
```

A row's children are its marker (an icon, dot or avatar), its label and an optional count with `data-menu-meta`. The tick slot is added for you.

## Rules

### Multi-select rows use `DropdownMenuCheckboxItem`

A row that toggles a choice inside a menu is a `menuitemcheckbox`, never a checkbox nested in a menu item. The menu stays open while you toggle, through `closeOnClick={false}`.

### On rows step forward, off rows step back

A checked row gets a leading tick and a full-colour, semibold label. Unchecked rows dim their marker (dot, icon or avatar), so the selection reads at a glance. Labels and counts keep the muted text colour, which meets WCAG AA contrast (6.9:1 on the menu surface); dimming them further fails it.

### The tick's slot opens and closes

Ticking opens a 16px slot with a spring, pushing the row along, then draws the tick. Unticking rewinds the tick first, then closes the slot.

### Radio rows match checkbox rows

A radio row behaves like a checkbox row: the chosen option gets the leading slot, a full-colour semibold label and a dot instead of a tick. The dot springs in from nothing once the slot has opened, and shrinks away quickly when another option is chosen. Single and multiple choice then read the same way, and only the mark tells them apart.

### Shortcuts sit a little in from the edge

Shortcuts and other trailing text get 4px more room on the right than the row's 8px padding, so letters such as ⌘D don't crowd the highlight's rounded edge. Trailing icons, such as the submenu chevron, keep the plain padding.
