## Overview

Four sections: a status, a sprint with its dates and points, one that starts collapsed, and one where nobody can create tickets. Click a header (or its chevron) to collapse it; click "+" to type a new ticket, and Escape or "×" to stop.

## Usage

The app's `SectionHeader` picks the icon and label (a status's, or a sprint's or epic's heading) and passes its messages.

```tsx
import { ListSectionBody, ListSectionHeader } from "@pp/ui/list-section"
import { StatusGlyph } from "@pp/ui/status-glyph"

<ListSectionHeader
  icon={<StatusGlyph icon={meta.icon} className={meta.className} color={meta.color} />}
  label={label}
  count={count}
  countLabel={m.tickets_section_count_aria_label({ count })}
  collapsed={collapsed}
  onToggleCollapsed={onToggleCollapsed}
  collapseLabel={m.tickets_section_collapse_aria_label({ label })}
  create={
    canCreate
      ? {
          creating,
          creator: <SectionTicketCreator … />,
          onStart: onStartCreate,
          onDismiss: onDismissCreate,
          label: m.tickets_section_create_aria_label({ label }),
          dismissLabel: m.tickets_section_create_dismiss_aria_label({ label })
        }
      : undefined
  }
/>
<ListSectionBody collapsed={collapsed}>{rows}</ListSectionBody>
```

| Prop | Type | What it does |
| --- | --- | --- |
| `icon` | `ReactNode` | In the status column: a `StatusGlyph`, or a sprint's or epic's icon |
| `label` | `string` | The section's name |
| `count`, `countLabel` | `number`, `string` | The count badge and what it reads out ("4 tickets") |
| `detail` | `ReactNode` | Muted text at the end (dates, points); hidden on narrow screens |
| `collapsed`, `onToggleCollapsed` | `boolean`, `() => void` | Open or closed; the whole header toggles |
| `collapseLabel` | `string` | The chevron's name |
| `create` | `SectionCreate` | The "+" and the inline creator; leave out where nobody can create tickets |

`ListSectionBody` takes `collapsed` and the rows. `StatusGlyph` (`@pp/ui/status-glyph`) is the status icon at list size, shared with board columns.

## Rules

### The header lines up with its rows

The chevron sits in the checkbox column (`--list-lead`) and the icon in the status column (`--list-icon`), so a section's icon stands right above its rows' status icons and the titles start on one line.

### Collapsing keeps the header where it is

Opening or closing a section changes the height of everything under it, which would move the page under the pointer. The toggle runs through `keepInPlace` (`@pp/ui/lib/keepInPlace`), which scrolls by the change so the header stays put on screen, and the next click lands on the same header.

### Creating happens in the header

"+" swaps the heading for the creator with a short blur crossfade, in the same spot, so the new ticket is typed where it will land. The "+" turns 45° into "×" to stop, and the header stops toggling while the creator is open, so a click into the field doesn't collapse the section.

### A closed section is out of reach

The collapsed body is `inert` and hidden from assistive tech, so Tab and screen readers skip rows nobody can see.
