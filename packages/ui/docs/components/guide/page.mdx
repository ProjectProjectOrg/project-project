## Usage

```tsx
import { Guide } from "@pp/ui/guide"

<Guide
  open={!seen && selected > 1}
  onClose={markSeen}
  target={() => list.current?.querySelector("[data-selected]")}
  title={m.tickets_guide_bulk_title({ count: selected })}
  doneLabel={m.tickets_guide_done()}
>
  {m.tickets_guide_bulk_body()}
</Guide>
```

| Prop | Type |
| --- | --- |
| `open`, `onClose` | whether it shows; "Got it", Escape, a click outside, or doing the thing closes it |
| `target` | a ref, or a function that finds the element it teaches |
| `title` | `string`: what to do, in a few words |
| `doneLabel` | `string`: the button that closes it ("Got it") |
| `step` | `string`: where it sits in a short series ("1 of 2") |
| `children` | how, in a sentence or two |

## Rules

### One thing, in place

A guide points at the real thing, on the real screen, at the moment it first applies: never a tour of the app, never a picture of it. The rest blurs (3px) and dims (`--guide-scrim`), and the spotlight gets the 2px `--ring` with 6px of room and 16px corners, so the eye goes straight to it.

### The spotlight stays live

The overlay has a hole over the target, so you can do what it teaches right there; doing it is the best way to close it. A click anywhere else, Escape or "Got it" also closes it, and focus goes back where it was.

### Once per person

The app remembers who has seen each guide and never shows it again. A guide that keeps coming back is noise.

### Beside, not over

The callout sits under the spotlight, or above it when there's no room, lined up with its start and kept 12px inside the window, on the popup surface. It follows the target if the page moves.
