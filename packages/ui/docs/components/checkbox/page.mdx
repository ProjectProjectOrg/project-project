## Overview

Every state at once. Hover, pressed and focus are pinned with `data-force`; the large row is live, so click it to see the motion.

<Demo name="overview" title="All states" />

## Usage

Wrap the checkbox in a `label` so the text toggles it too. The label is the accessible name; without one, pass `aria-label`.

```tsx
import { Checkbox } from "@pp/ui/checkbox"

<label className="flex items-center gap-2 text-body">
  <Checkbox checked={includeTags} onCheckedChange={setIncludeTags} />
  {m.templates_save_as_include_tags()}
</label>
```

| Prop                         | Type                         | Default     |
| ---------------------------- | ---------------------------- | ----------- |
| `checked` / `defaultChecked` | `boolean`                    |             |
| `indeterminate`              | `boolean`                    | `false`     |
| `onCheckedChange`            | `(checked: boolean) => void` |             |
| `variant`                    | `"default" \| "quiet"`       | `"default"` |
| `disabled` / `readOnly`      | `boolean`                    | `false`     |

Every other prop goes to Base UI's `Checkbox.Root`.

## Rules

### Squircle box, ink fill

The box has squircle corners (`corner-shape: squircle`), with a 4.5px rounded fallback in browsers without it. Unchecked, it shows a 1.5px ring at 30% ink, which meets the 3:1 contrast that a control's edge needs.

### Ticking blooms, unticking rewinds

Ticking scales the fill up from 40% with a light spring, then the tick draws on 60ms later. Unticking rewinds the tick and shrinks the fill in about 150ms. Reduced motion keeps only a fade.

### Press and focus

A press scales the box to 97%, the app-wide press standard. Keyboard focus shows a blue ring with a 2px gap. The hit area reaches 8px past the box.

### Indicator

`CheckboxIndicator` is the box alone, with no input of its own: for an item that is itself the control (a toggle row with `aria-pressed`), or for markup that can't mount a checkbox per item. It takes `variant` like the checkbox, and every other prop goes to its `span`. A virtualized ticket row gives it `role="checkbox"`, `aria-checked`, `tabIndex`, a label and `aria-hidden={undefined}` (it is hidden by default), and its list handles the toggle.
