# Contributing

ProjectProject is not accepting outside code contributions until a root `LICENSE`
file is present.

The intended project license is `AGPL-3.0-only` for the main application code,
after ownership and licensing clearance is complete. Once that license is added,
contributions to licensed files are accepted under the same license as the files
being changed.

By contributing after the license is added, you certify that:

- You have the right to submit the contribution.
- The contribution is your original work, or you have permission to submit it
  under the project license.
- The contribution does not contain confidential information, employer-owned
  code, proprietary source, private credentials, or third-party material that
  cannot be redistributed under the project license.
- You understand that ProjectProject trademarks and branding are not licensed
  under the code license.

If you are contributing on behalf of an employer or using employer equipment,
get written permission before submitting code.
